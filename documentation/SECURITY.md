# Локальные данные и секреты

Публичный репозиторий содержит код, пустые настройки и вымышленные демонстрационные данные. Рабочие конфиги, cookies, ключи, персональная статистика, браузерные профили, переписка, выгрузки, журналы и зашифрованные архивы исключены из Git.

## Шифрование локального файла

```bash
python3 -m pip install -r requirements-security.txt
python3 tools/seal_config.py encrypt config.local.yaml config.local.yaml.sealed
python3 tools/seal_config.py decrypt config.local.yaml.sealed recovered.local.yaml
```

Пароль вводится интерактивно в терминале и не передаётся в аргументах команды. Файл защищается AES-256-GCM, ключ получается из пароля через scrypt; соль и nonce создаются заново при каждом шифровании. Повреждённые данные или неправильный пароль не дают создать расшифрованный файл. Новый файл создаётся с правами 600; существующие файлы не перезаписываются, исходник сохраняется.

Описание используемых примитивов: [AES-GCM](https://cryptography.io/en/latest/hazmat/primitives/aead/#cryptography.hazmat.primitives.ciphers.aead.AESGCM) и [scrypt](https://cryptography.io/en/latest/hazmat/primitives/key-derivation-functions/#scrypt).

Храните и исходные, и зашифрованные локальные файлы вне Git. Этот инструмент не меняет автоматически настройки других установленных приложений.

## Проверка публикации

```bash
python3 tools/check_public_tree.py --staged
gitleaks dir . --redact=100
gitleaks git . --redact=100
```

Проверка читает Git-индекс, отклоняет рабочие пути, личные адреса, неизвестные двоичные файлы и метаданные изображений. Разрешены только указанные демонстрационные PNG и известные лицензированные шрифты с проверенными контрольными суммами. Содержимое изображений отдельно проверяется визуально; автоматическая проверка не заменяет проверку новых материалов человеком.
